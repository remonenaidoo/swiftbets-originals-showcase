# Gilded Savanna artwork

Generated with Flux 1.1 Pro / Ultra (BFL) from `prompts.json` by `gen.py` (`BFL_API_KEY` in the environment).
`concept-sheet.jpg` set the style; each asset was then generated on its own, backgrounds removed with rembg
(isnet-general-use), and sized into `../public/assets`. Raw renders stay out of git (`raw/`).
Chosen variants: logo = `logo2` (seed 47), wild = `wild1` (seed 19).
