# Sardine Run: maths document

Sardine Run is a theme on the Cape Point Ways engine: `OneShotGames.All` registers it as `new WaysSlot("sardine-run", "Sardine Run")`, the same class with the same strips, pays, feature and 5,000× cap. Only its id, its name and its page's art differ. Its RTP, hit rate and simulation are therefore Cape Point Ways', in [cape-point-ways.md](cape-point-ways.md).
