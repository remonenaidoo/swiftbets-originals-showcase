## The rule

Each shared round's crash point is fixed before betting opens from its seed (shown hashed, revealed after the crash): u = the first Fair float of (seed, "crash", round number); point = floor(96 / (1 − u)) / 100, at least 1.00×, at most 5,000×. Then P(point ≥ x) = 0.96 / x for every x on the 0.01 grid up to 5,000×, so a bet whose auto cash-out is x wins x with probability 0.96 / x: RTP 96% for every target. A manual cash-out pays the multiplier shown at the moment the server receives it (floored to 0.01×), which is never above what an auto target set to that value would have paid.

The multiplier at t ms into the flight is e^(0.00006 t): 2× at 11.6 s, 10× at 38.4 s, 100× at 76.8 s, 5,000× at 142 s. A round crashes at 1.00× (before anyone can cash out) with probability 1 − 0.96 / 1.01 = 4.9505%.
