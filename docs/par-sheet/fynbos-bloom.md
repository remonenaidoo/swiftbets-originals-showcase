# Fynbos Bloom: maths document

Fynbos Bloom is a theme on the Kalahari Gem Fall engine: `OneShotGames.All` registers it as `new CascadeSlot("fynbos-bloom", "Fynbos Bloom")`, the same class with the same strips, pays, feature and 5,000× cap. Only its id, its name and its page's art differ. Its RTP, hit rate and simulation are therefore Kalahari Gem Fall's, in [kalahari-gems.md](kalahari-gems.md).
