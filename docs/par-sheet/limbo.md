## The rule

Choose a target x from 1.01× to 5,000× in 0.01× steps. The result is Crash's draw: floor(96 / (1 − u)) / 100, at least 1.00×, at most 5,000×, so P(result ≥ x) = 0.96 / x exactly for every x on the 0.01 grid. A result at or above the target pays the target: RTP = x × 0.96 / x = 96.0000% for every target.

The draw is the same as Crash's, measured over 1,000,000,000 rounds in [crash.md](crash.md).
